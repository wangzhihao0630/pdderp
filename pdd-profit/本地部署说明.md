# 本地部署说明

把这套网站在你自己的电脑上跑起来，5 分钟搞定。不需要买服务器、不需要备案、不需要数据库。

---

## 一、第一步：安装 Node.js（只需装一次）

1. 打开 https://nodejs.org
2. 点绿色的 **LTS（长期支持版）** 按钮下载
3. 双击安装包，一路点「下一步」直到完成（全部默认选项即可）
4. **装完必须重启一次电脑**（不重启 PATH 不生效，这是最常见的失败原因）
5. 验证：按 `Win + R` → 输入 `cmd` → 回车 → 输入：

```
node -v
```

看到 `v22.x.x` 就是装好了。如果显示"不是内部或外部命令"，说明没装成功或没重启，回到第 3 步。

> Mac 用户也可以用 `brew install node`。后面的步骤完全一样。

---

## 二、第二步：解压 + 启动

### ⚠️ 先解压，别在压缩包里双击

Windows 自带的资源管理器能"打开"zip 并双击里面的文件，但那样是运行在临时目录里，**找不到 server.js，一定会失败**。

正确做法：右键 `pdd-profit.zip` → **全部解压缩** → 得到 `pdd-profit` 文件夹 → 进去再双击 `start.bat`。

### 启动

| 系统 | 操作 |
|---|---|
| **Windows** | 双击 `start.bat` |
| **macOS / Linux** | 终端 `cd` 到项目目录，执行 `chmod +x start.sh && ./start.sh` |

正常会看到 4 步自检，全部 OK 后浏览器自动打开：

```
[STEP 1/4] Checking current folder...
[STEP 2/4] Checking Node.js ...   Node.js OK
[STEP 3/4] Checking files ...     Files OK
[STEP 4/4] Starting server ...

  DO NOT CLOSE THIS WINDOW
  Home   : http://localhost:3000
  Admin  : http://localhost:3000/admin.html
```

**那个黑窗口不能关！** 它就是网站服务本身，关掉 = 网站停止。最小化可以。

## 三、双击 start.bat 闪一下就关了 / 报错怎么办

新版 `start.bat` 已经内置诊断，**无论成功失败都会停下来等你按键**，不会直接闪退。根据它停在哪个步骤判断：

### 停在「ERROR: Node.js is NOT installed」

说明系统找不到 node。三步排查：

1. `cmd` 里输入 `node -v`，如果提示"不是内部或外部命令" → 真没装好，重装一次，**装完重启电脑**
2. 如果 `cmd` 里能显示版本号，但 bat 里检测不到 → 说明你装完没重开过任何窗口，重启电脑即可
3. 装的是 **Node.js 而不是"Node.js runtime"**，确认官网下的是 LTS 版本

### 停在「ERROR: server.js NOT FOUND」

说明运行位置不对。**先把 zip 完整解压**，然后确认 `start.bat` 和 `server.js` 在**同一个文件夹**里（不要把 bat 单独拷到桌面）。

### 窗口依然一闪而过、什么都看不到

用命令行手动启动，这样错误信息一定会显示出来：

1. 打开 `pdd-profit` 文件夹
2. 在地址栏里**直接输入 `cmd`** 然后回车（会在当前目录打开命令行，这招很省事）
3. 输入：

```
node server.js
```

把屏幕上出现的**红色报错**原样发给我，我直接给你定位。

### 命令行里启动报 `EADDRINUSE: address already in use :::3000`

端口被占用（通常是之前已经启动了一个没关）。两个办法：

- 关掉之前那个黑窗口
- 或者换个端口启动：

```bash
# Windows
set PORT=8080 && node server.js

# Mac / Linux
PORT=8080 node server.js
```

然后用 `http://localhost:8080` 访问。

### 中文显示成乱码

不影响运行。这是 Windows 命令行默认 GBK 编码导致的显示问题，功能完全正常，可以忽略。

## 五、让同一 WiFi 下的手机/其他电脑也能访问

1. 查本机 IP：`cmd` 里输入 `ipconfig`，找「IPv4 地址」，一般是 `192.168.1.xxx`
2. 手机浏览器输入 `http://192.168.1.xxx:3000`

**打不开基本都是防火墙**：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 找到 `Node.js`，把「专用」和「公用」都勾上。

> 自己用的话不用折腾，`localhost` 完全够。

## 六、你的数据存在哪

```
pdd-profit/data/
├── db.json          ← 用户、订单、套餐、公告（最重要，定期备份！）
└── uploads/         ← 你上传的收款码图片
```

**备份**：把 `data` 文件夹复制到 U 盘或网盘，就是全量备份。
**换电脑**：把 `data` 文件夹拷到新电脑同样位置，用户和订单都还在。

---

## 七、想让它一直开着

1. **不关机**：最简单，窗口最小化挂着
2. **开机自启**：`Win + R` → 输入 `shell:startup` → 把 `start.bat` 的**快捷方式**拖进去
3. **搬到服务器**：这才是正式做法，见 `docs/上线盈利指南.md`，轻量服务器 60~100 元/月，7×24 在线还能绑域名
